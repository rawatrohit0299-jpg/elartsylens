# **App Name**: El Artsy Lens Portfolio

## Core Features:

- Hero Section Display: Display an engaging hero section with oversized typography headline, optional sub-descriptor, vertical social links, and a dark/light mode toggle.
- Masonry Grid: Asymmetrical masonry layout for displaying 'Recent Work' with rounded corners, soft shadow, and a hover effect to subtly zoom in and reveal the title.
- Collections Display: Split layout for showcasing collections with a title, short story, 'View Collection' button, optional external link, and a large cinematic image or video with a play button.
- Journal Display: Blog-style photo essays with a large cover image, minimal text, and scroll-based storytelling.
- Image Enhancement Tool: An AI-powered tool to automatically enhance uploaded images by adjusting contrast, brightness, and sharpness to fit the portfolio's aesthetic.

## Style Guidelines:

- Primary color: Dark charcoal gray (#333333) to establish a sophisticated, minimalist base.
- Background color: Near-white (#F5F5F5), offering ample whitespace to highlight content without overwhelming the user.
- Accent color: Muted steel blue (#6699CC), providing a subtle highlight for interactive elements and calls to action.
- Headings: 'Space Grotesk' (sans-serif) in bold for a modern, attention-grabbing title.
- Body: 'Inter' (sans-serif) for a clean, neutral reading experience. 
- Minimalist line icons for navigation and utility functions. Use feather icons.
- Asymmetrical masonry grids and split layouts to give an editorial feel.
- Smooth scrolling and subtle fade-in/slide-in animations on content load.
